# Overstack · AMS模块化收纳底座

把打印板、工具和耗材设备收在同一套底座里。当前组合从下到上是五槽板层、八槽板层、单抽屉层、双抽屉层、三抽屉层，最上面放AMS 2 Pro与AMS HT。

打印板两侧托条延伸到后挡，底层前封闭面与承架一体。每层单独装配，层与层通过定位脚和后方锁片连接。

整套外廓495 × 287 × 309 mm，共58个零件。文件按层整理，每层附独立中英文组装教程。STL单位毫米，3MF是装配几何，不是切片工程。

当前为数字样机，图片均为CAD渲染。已经做过装配干涉、抽屉行程及通用PETG/FDM检查；尚未实物试装、验证承重或完成整套实际切片。不要将本页写成已验证成品。正式发布前补上实际打印配置、组装照片和设备适配结果。

建议标签：AMS、AMS HT、收纳、抽屉、打印板、模块化。

所有抽屉均为2 mm实心底板，单抽屉改用加厚的左右拼接，滑轨接口保留。从社区已有模型的实践为参考设计基础。
