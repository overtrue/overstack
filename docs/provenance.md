# Design basis / 设计基础

从社区已有模型的实践为参考设计基础。

The design is based on practical experience with existing community models.

Overstack is built from parametric geometry. The build does not require external model meshes. It uses 2 mm solid drawer floors and uses a reinforced left/right joint for the wide single drawer while retaining the slide interfaces.

All illustrations are CAD renders. Physical fit and load capacity remain unverified.
